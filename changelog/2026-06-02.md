# Changelog — 2026-06-02

## Agentic Development Bootstrap — `ai/` Directory

Bootstrapped a domain-agent and skills library in `ai/` to accelerate parallel bug-fix delivery toward production MVP. The library is grounded in five audit reports (2026-05-30) that identified ~25 critical issues across backend, frontend, infrastructure, CI/CD, and deployment.

### System Context (`ai/system/`)
- **`system-prompt.md`** — shared context injected into every agent session: project identity, stack versions, DynamoDB key patterns, Lambda handler contract, autonomy gates, commit conventions, and changelog/notes conventions.

### SKILLS.md Decomposition
Refactored `ai/skills/SKILLS.md` from a 476-line "god document" into a 193-line index + conventions file:
- **Removed** (content moved to authoritative locations): project overview, architecture principles, DynamoDB key patterns, Lambda handler pattern, AI prompting patterns, autonomy model
- **Kept**: navigation index (§0), project conventions (§1 — auth flow, statement import, analytics, troubleshooting, testing cheatsheet), common pitfalls (§2), env var management (§3), system review protocol (§4)
- **Autonomy model**: agents code, test, and commit to feature branches autonomously; all deploys require human approval

### Autonomy Model
- **Autonomous:** edit files, run tests, `git commit` to feature branches
- **Human gate:** `git push`, PR creation, `npm run deploy:*`
- **Branch convention:** `fix/<domain>/<audit-id>` (e.g. `fix/backend/CON-001`)
